# TimeCycle

TimeCycle is a simple interval reminder app built for focus and rest. It
lets you configure two phases (A/B), select cue text, and run repeated
cycles with notification-based reminders.

## Run

1. Open `TimeCycle.xcodeproj` in Xcode.
2. Select the `TimeCycle` scheme and a device or simulator.
3. Run the app (`Cmd+R`).
4. When prompted, allow notifications so reminders can play.

## Notes

- Notification delivery and timing are subject to iOS scheduling limits.
- Background/locked behavior is controlled by system policies.
